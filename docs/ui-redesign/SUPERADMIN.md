# Superadmin — SaaS Control Center

- Sidebar: OVERVIEW (Dashboard, Analytics), SAAS (Users, Workspaces, Plans, Subscriptions), REVENUE (Manual Payments, Coupons, Revenue Reports), CONFIG (Branding, Settings, Audit Logs) + Blog + Back to workspace. Collapsible, filter `/` client-side, mobile drawer.
- Header: breadcrumb Platform/title, global search → users?search, notification center (pending counts), theme toggle, profile.
- KPI: users, workspaces, active paid, free, MRR IDR/USD + growth vs bulan lalu.
- Analytics: 12-week user/workspace/MRR, plan distribution, revenue by currency, conversion, churn (null bila data tipis).
- Subs: counts active/pending/expired, filter JS, renewals ≤14d, recent 10.
- Payments: pending + approve/reject inline, approved MAN-*, recent invoices.
- Activity: new users/workspaces, audit log 8. Quick actions 6 tombol.
